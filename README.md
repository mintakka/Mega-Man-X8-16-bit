## About
Mega Man X8 16-bit is a reimagining of the PS2 original with SNES styled graphics. The aim was to demake X8 in a similar feel to the first three Mega Man X games, while trying to actually finish a low-scope fangame. This fangame is fully playable from start to finish with X and runs on Godot Engine 3.5.

This public, noncommercial derivative is **Mega Man X8 16-bit: Zashiko Edition**. It integrates Tchy258's Zashiko Mod 1.0.0.4-b and its native X, Zero, and Axl campaigns with Linux and ARM64 Android support. Tchy258 is credited for the Zashiko Mod architecture, playable characters, adaptations, dialogue, artwork integration, localization, and related game features. The complete histories of both projects are preserved in Git.
